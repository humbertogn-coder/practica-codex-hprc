# Practica Codex HPRC

Este proyecto sirve para practicar un flujo reusable:

1. Correr Python en mi computadora con Anaconda.
2. Editar el proyecto con VS Code.
3. Usar Codex para entender y mejorar el codigo.
4. Subir el proyecto a GitHub.
5. Correr el mismo proyecto en HPRC.

## Ejecutar localmente

```bash
conda activate codex-practica
python main.py
